ZQ-153 · WeChat login → 微信号 + 显示名（微信名）

微信号 wechatId
--------------
On POST /api/auth/wechat, if profile.wechatId is empty:
  wechatId = sanitizeWechatId(openid)
  (typical openid already matches ^[A-Za-z0-9_-]{3,32}$)
  else wechatId = "w" + sha256("wxid:"+openid)[:31]
Never overwrite a user-set wechatId.
nickName is NEVER used as wechatId.

显示名 displayName
-----------------
Default to WeChat nickName from login body / type=nickname input.
Fill only when empty, missing, or placeholder (e.g. 微信用户).
Never overwrite a real custom displayName.

Also
----
- wechatContactSatisfied: explicit wechatId OR bound openid
- getSession lazy-backfills wechatId for already-bound accounts
- needsProfileSetup treats placeholder display names as incomplete
- MP shell caches wechatId + displayName (miniprogram/utils/session.js)
